## 🚀 Prochains déploiements (Full Stack)

### 2. Frontend Angular → Vercel

**Méthode 1 : CLI (rapide)**
```bash
# Installer Vercel CLI
npm i -g vercel

# Login (une fois)
vercel login

# Déployer
cd frontend
vercel --prod
```

**Méthode 2 : GitHub (automatique)**
1. Va sur https://vercel.com/new
2. Importe `MoussaBoaz/laravel-angular-starter`
3. Framework preset : **Other**
4. Root directory : `frontend`
5. Build command : `npm run build`
6. Output directory : `dist/frontend/browser`
7. Deploy

**URL résultat :** `https://laravel-angular-starter.vercel.app`

---

### 3. Backend Laravel → Render

1. Crée un compte : https://dashboard.render.com/
2. Clique **New +** → **Blueprint**
3. Connecte ton repo GitHub
4. Render détecte automatiquement `backend/render.yaml`
5. Clique **Apply**

**URL résultat :** `https://laravel-api.onrender.com`
