## GitHub Setup

### 1. Create Repository
Go to https://github.com/new and create:
- Repository name: `laravel-angular-starter`
- Public (for free version)
- Add README: No
- Add .gitignore: No
- Choose a license: No

### 2. Push Code

```bash
cd /home/node/.openclaw/workspace/projects/laravel-angular-starter

# Initialize git
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit: Laravel + Angular starter kit"

# Add remote (replace with your repo URL)
git remote add origin https://github.com/moussab31/laravel-angular-starter.git

# Push
git push -u origin main
```
